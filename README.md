## Projects

**Community disaster reporting system** (capstone, code is private)
A reporting and dispatch system for a city disaster risk reduction office. It was a group capstone, and I designed and built all three apps and the backend. Residents send geotagged reports with photos from a mobile app. Responders see incoming incidents on their own mobile app with a map. Office staff watch new reports appear live on a map in the web portal and manage accounts from there. Staff logins use MFA, access is split into admin, operator, and responder roles, and the database enforces row-level security. Push notifications and follow-up reminders run as Supabase Edge Functions.
Next.js, Expo (React Native), TypeScript, Supabase (Postgres, PostGIS, Realtime, Edge Functions), Mapbox

React, TypeScript, Tailwind, Cloudflare Pages Functions, D1, Python
